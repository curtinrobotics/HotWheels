# Legacy hardware reference

`legacy_d1_mini.kicad_sch` preserves the original Wemos D1 Mini circuit and signal labels for reference. It is not part of the Rev A electrical design, BOM, or ERC scope.

The active Rev A schematic is `../Hot_Wheels_Electronics/Hot_Wheels_Electronics.kicad_sch` and uses the directly mounted ESP32-WROOM-32UE module.
